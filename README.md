# Crafting Slab

Half-height crafting table for NeoForge. Keeps the 3x3 grid when you close the GUI.

## Details

| | |
|---|---|
| Minecraft | 1.21.11 |
| Loader | NeoForge 21.11.x |
| Mod ID | `craftingslab` |
| Version | 1.0.0 |

## Features

- Crafting table as a slab (top, bottom, and double)
- Full 3x3 crafting GUI with recipe book
- Grid contents persist when the menu closes
- Nearby Crafting support (craft from nearby chests)
- Stored grid items render on the slab surface
- Furnace slab with full smelting GUI
- Breaking slabs drops leftover contents
- Vanilla crafting-table / furnace look

## Recipes

Shapeless:

- **1x Crafting Table** → **2x Crafting Slab**
- **1x Furnace** → **2x Furnace Slab**

## Required Dependency

- **Nearby Crafting** (+ Recipe Book Access API) — craft from nearby chests via the recipe book

## Optional Compat

- **JEI** — recipe transfer / catalyst support
- **Crafting Tweaks** — grid buttons on the crafting slab menu

## Install

1. Install NeoForge for Minecraft 1.21.11
2. Drop `craftingslab-1.0.0.jar` into your instance `mods` folder
3. Launch the game
